# Информационная система учета строительных материалов

## Стек
- Python 3
- Flask
- SQLite
- SQLAlchemy
- Flask-Login

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Инициализация базы данных

Создает таблицы и пользователя администратора.

```bash
flask --app run.py init-db --admin-username admin --admin-password admin
```

Если ты обновлял проект и менялась схема (например добавились новые таблицы `audit_log` или поле `barcode` у материалов), проще всего удалить файл базы и инициализировать заново:

1) останови сервер
2) удали файл `database.sqlite3` в папке проекта
3) снова выполни команду `init-db`

После этого можно входить:
- логин: `admin`
- пароль: `admin`

## Запуск

```bash
python run.py
```

Открой в браузере:
- `http://127.0.0.1:5000/`

## Роли
- `admin` — полный доступ + управление пользователями
- `storekeeper` — материалы/объекты/поставки/списания
- `manager` — просмотр списков и отчетов

## Функции для демонстрации
- Белая тема по умолчанию + переключатель темы в меню
- Фильтры/поиск/пагинация в списках и отчетах
- Экспорт отчетов и списков в CSV
- Журнал операций (audit log)
- Штрихкод материалов (уникальный идентификатор для инвентаризации)

## Демо-данные

Заполняет базу примерами материалов/объектов/поставок/списаний и создает пользователей для демонстрации:

```bash
flask --app run.py seed
```

Пользователи демо:
- `storekeeper` / `storekeeper`
- `manager` / `manager`

Чтобы пересоздать демо-данные:

```bash
flask --app run.py seed --force
